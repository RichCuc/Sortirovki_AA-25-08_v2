# Сравнение сортировок АА-25-08

В `files.txt` перечислены 18 входных файлов. Каждый обрабатывается шестью
алгоритмами: std::sort, Radix, Comb, Heap, Gnome и Shaker. Полный запуск
должен завершиться результатом: 18/18 файлов, 108 сортировок, 0 ошибок.
Каждый результат сравнивается с эталоном std::sort.

## Сборка и запуск

В Visual Studio 2022 откройте `Sortirovki.sln`, выберите Release и x64,
затем нажмите Ctrl+F5. Проект настроен на установленный MSVC 14.44.35207.
Для русских сообщений в стандартной консоли Windows используется CP866.

Нужен C++20: поразрядная сортировка использует std::format.
Запускайте программу из папки с `main.cpp` и `files.txt`.

Clang с поддержкой std::format в стандартной библиотеке:

```sh
clang++ -std=c++20 -O2 *.cpp -o sorts
./sorts
```

MSVC в Developer Command Prompt для x64:

```bat
cl /std:c++20 /O2 /EHsc /utf-8 *.cpp /Fe:sorts.exe
sorts.exe
```

Файлы содержат только числа через пробелы или переводы строк.
Дробная часть отделяется точкой; отдельного числа размера в начале нет.

## Тесты шейкерной сортировки

Взяты файлы из версии старого проекта, указанной в презентации:
`RichCuc/Sortirovki_AA2508`, коммит `ad029f8620181672fa951ab7f8201c66ca8dad9c`.
Они соответствуют слайду «Шейкерная: входные данные»:

| Файл | Чисел | Порядок | Сравнений | Обменов |
| --- | ---: | --- | ---: | ---: |
| shaker_best.txt | 100 | Возрастающий | 4 950 | 0 |
| shaker_average.txt | 1 000 | Перемешанный | 499 500 | 249 683 |
| shaker_worst.txt | 10 000 | Убывающий | 49 995 000 | 49 995 000 |

Это наглядные сценарии с разными размерами, как в презентации.
Здесь одновременно меняются размер и порядок данных. По их времени
нельзя судить только о влиянии порядка при одинаковом n.

Алгоритм сохранён без флага обменов и раннего выхода. Он выполняет
n(n-1)/2 сравнений при любом порядке, поэтому при фиксированном размере
все случаи остаются квадратичными. Убывающий массив даёт максимум
соседних обменов, но не обязан быть самым медленным среди входов того же
размера. Нагрузка и работа процессора также влияют на секундомер.

Общий `main.cpp` выполняет полную проверку: 18 файлов, 6 методов,
108 запусков. Для сравнения шести методов только на наших трёх файлах
нужен отдельный рабочий каталог с этими файлами и `files.txt`, содержащим
только три их имени: получатся 3 файла и 18 запусков.

Для трёх запусков только шейкерной откройте в Visual Studio
`shaker_check/ShakerCases.vcxproj`, выберите Release x64 и нажмите Ctrl+F5.
Этот отдельный проверочный проект использует исходный `shakerSort`,
показывает три времени и сравнивает все результаты с std::sort.
Эталон подготавливается вне замера и не считается отдельным запуском.
Основной `main.cpp` и исходники сортировки при этом не меняются.

Не следует выбирать только самый быстрый прогон. Для оценки времени
повторяют запуски и берут медиану. Файлы `size_100.txt`, `size_1000.txt`
и `size_10000.txt` показывают рост времени на размерных случайных входах.
